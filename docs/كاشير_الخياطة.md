ويستطيع النظام:

**العمل Offline → حفظ كل شيء → الاستمرار → المزامنة لاحقًا → اكتشاف التعارض → التعافي دون فقدان العمليات.**

# COMMAND TO THE DEVELOPMENT AGENT

لا تنتظر تعليمات تفصيلية.

افحص النظام الحالي، اكتشف الاختناقات، وحدد أكبر فرص تسريع العمل، ثم نفذها.

إذا وجدت Architecture تمنع Offline-First الحقيقي، أصلحها.

إذا وجدت Database تمنع السرعة، أعد فهرستها/تصميمها.

إذا وجدت UI يفرض إدخالًا متكررًا، أعد تصميمه.

إذا وجدت Feature مرتبطة بنوع نشاط بشكل Hard-coded، حوّلها إلى Capability.

إذا وجدت عملية يمكن أتمتتها، حوّلها إلى Workflow.

إذا وجدت بيانات يمكن أن تنتج قرارًا ذكيًا، اجعل النظام يقترح القرار.

إذا وجدت وظيفة تعتمد على الإنترنت بلا ضرورة، انقلها إلى Local-First.

إذا وجدت خطأ أو Race Condition أو مشكلة Sync، أصلحها ولا تخفها.

**DO NOT BUILD MORE SCREENS.
BUILD LESS WORK.**

**DO NOT BUILD A CASHIER.
BUILD A BUSINESS ACCELERATOR.**

**DO NOT MAKE THE USER OPERATE THE SOFTWARE.
MAKE THE SOFTWARE OPERATE THE BUSINESS WITH THE USER.**
