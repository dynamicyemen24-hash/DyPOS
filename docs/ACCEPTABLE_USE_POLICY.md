# سياسة الاستخدام المقبول

**تاريخ السريان: 7 أكتوبر 2026**

يحظر استخدام DyPOS في الوصول غير المصرح، التحايل على المصادقة أو الصلاحيات، استخراج بيانات مشترك آخر، البرمجيات الضارة، الاحتيال، تعطيل الخدمة، أو إساءة استخدام واجهات التكامل.

يجب استخدام حسابات وصلاحيات مناسبة لكل موظف، وعدم مشاركة بيانات الاعتماد بطريقة تلغي المساءلة. كما يجب ألا يُدخل المستخدم بيانات لا يملك حق معالجتها أو نقلها.

قد تُطبق قيود أو تعليق مؤقت أو إنهاء للحساب عند وجود خطر أمني أو مخالفة جسيمة، مع مراعاة العقد والقانون المطبق.
