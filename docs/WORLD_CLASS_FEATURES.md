# الجولة الثانية: الأجهزة والبحث — `Hardware & Arabic-Fuzzy Round`

## 3️⃣ ربط موازين البضائع الموزونة — `src/utils/scale.js` ⚖️
| البند | الوصف |
|-------|-------|
| البروتوكولات | يقرأ نصوص الميزان الفعلية: **CAS** (`ST,GS,+ 1.234kg`)، **Mettler/Sartorius** (`S+0001.234kg`، `SI+0012.345 kg`)، النصوص الرقمية (`+1.5`)، والوحدات `kg/g/lb` |
| الاستقرار | يكشف راية `ST` المستقرة وتمييز `S/SI` — فلا يُضاف وزن متذبذب |
| الحساب التجاري | `quantityFromWeight` (تحويل لـ UOM البند) + `weightLineTotal` (سعر×كمية بتقريب نقود قابل للحقن) |
| السلامة | يرفض القمامة والمدخلات الفارغة/غير النصية بتقرير `{ok, reason}` — لا استثناءات |
| الاختبارات | `tests/scale.test.js` — **17 اختبارًا** (صيغ البروتوكول، الغرام/الرطل، الاستقرار، الرفض، التقريب، القيم الفاسدة) |
| جاهزية الربط | الناقل (serial-to-WebSocket/العامل الأوفلاين) يُغذّي هذه الدوال — **لا تغيير على أي مكوّن حالي** |

## 4️⃣ بحث متسامح عربي — `src/utils/fuzzyMatch.js` 🔍
| البند | الوصف |
|-------|-------|
| Levenshtein | مسافة تعديل نطاقية (bounded) مع معالجة `null` كسلسلة فارغة |
| التطبيع العربي | يعيد استخدام `normalizeArabic` (همزات، تشكيل، ى/ي، ة/ه، أرقام ٠-٩/۰-۹) على **الطرفين** |
| المطابقة الذكية | تعزيز الكلمة المضمّنة (بحث "قلم" يجده في "قلم رصاص") + عتبة تشابه قابلة للضبط |
